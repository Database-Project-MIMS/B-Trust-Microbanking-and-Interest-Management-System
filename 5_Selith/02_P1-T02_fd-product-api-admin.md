## What This Task Is

Build the API endpoints and administration page for FD products. Users with the right role can view all products and their rate history; only privileged users can edit rates. This is a **read-mostly** product view — FD products rarely change.

## How to Implement

### Step 1 — FD Product Service (`services/fd-product-service.ts`)

```typescript
/** Lists all FD products. Reads within a single query. */
export async function listFdProducts(): Promise<FdProduct[]> {
  const result = await query(`
    SELECT fd_plan_id, plan_name, tenure_months, interest_rate,
           description, status, effective_from, effective_to,
           created_at, updated_at
    FROM fd_plan
    ORDER BY tenure_months ASC
  `);
  return result.rows;
}

/** Updates an FD product's rate or status. Wraps in a transaction for audit. */
export async function updateFdProduct(
  id: string,
  updates: { interestRate?: string; status?: string; description?: string }
): Promise<FdProduct>
```

**Rules:**
- Money/rates are always strings across the API boundary, never JavaScript floats
- Rate changes should create effective-dating records (set `effective_to` on old, insert new)
- The service owns the transaction boundary

### Step 2 — GET `/api/fd-products`

```typescript
export async function GET(request: Request) {
  const user = await requireUser(request);
  // Any authenticated user can view products
  
  const products = await listFdProducts();
  return Response.json({ data: products });
}
```

**Response shape:**
```json
{
  "data": [
    {
      "fdPlanId": "...",
      "planName": "6 Month FD",
      "tenureMonths": 6,
      "interestRate": "0.1300",
      "status": "ACTIVE",
      "effectiveFrom": "2025-01-01",
      "effectiveTo": null
    }
  ]
}
```

### Step 4 — Frontend: FD Product Admin Page (`app/fd-products/page.tsx`)

Build a page that displays:

- **Rate history** — show effective-from/to dates for rate changes

### Step 5 — Write Tests (`tests/api/fd-products.test.mjs`)

| Test | What it verifies |
|---|---|
| `GET /api/fd-products` → returns 3 products | Seed data correct |
| Rates are returned as string fractions (e.g. `"0.1300"`) | Money as string |
| Non-authenticated request → `401` | Auth required |
| `PATCH` by ADMIN → rate updated | Admin access |
| `PATCH` by AGENT → `403` | Non-privileged denied |
| `PATCH` by BRANCH_MANAGER → `403` | Non-privileged denied |
| Invalid rate (> 1 or ≤ 0) → `400` | Validation |
| CSRF token missing on PATCH → `403` | CSRF enforced |
