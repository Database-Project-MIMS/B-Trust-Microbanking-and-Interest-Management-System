# Checkpoints

One snapshot per phase boundary: what shipped, what didn't, and an explicit go/no-go for
starting the next phase. Written by the lead (with input from all members) when a phase's
exit criteria in `docs/phases/phase-NN-*.md` are checked off — not before.

Filename: `phase-NN-checkpoint.md`.

## Format

```markdown
# Phase NN Checkpoint

Date. Exit criteria: met / not met (list what's outstanding).
What shipped. What slipped, and why. Go / no-go for next phase, and any conditions.
```
